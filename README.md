# John Russel Montaño — Professional Portfolio

Static portfolio website prepared for GitHub Pages at:

`https://azaresjrm.github.io`

## Repository structure

- `index.html` — main portfolio page
- `assets/styles.css` — responsive layout and visual styling
- `assets/site.js` — mobile navigation, animations, and active navigation state
- `assets/` — portrait, TrackIT screenshots, and downloadable resume
- `.nojekyll` — tells GitHub Pages to serve the files directly

## Deploy with GitHub Pages

1. Create a public GitHub repository named exactly `azaresjrm.github.io`.
2. Upload every file and folder from this directory to the repository root. Keep `index.html` at the root.
3. Commit the files to the repository's `main` branch.
4. Open the repository on GitHub and go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. After GitHub finishes deploying, open `https://azaresjrm.github.io`.

## Preview locally

You can open `index.html` directly in a browser. For the most accurate preview, run a simple local web server from this directory and open the address it provides.
